🚀 What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language for creating Web pages.

Key Points:

  • Standard markup language
  • Describes the structure of a Web page
  • Consists of a series of elements

How HTML works:

HTML elements tell the browser how to display the content.

<p>This is a paragraph.</p>

📄 Basic HTML Structure

Every HTML document has a required structure:

<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
  </body>
</html>

Structure Breakdown:

  • <!DOCTYPE html> Defines that this document is an HTML5 document
  • <html> The root element of an HTML page
  • <head> Contains meta information about the HTML page
  • <body> Defines the document's body

🏷️ HTML Attributes

Attributes provide additional information about elements:

<a href="https://example.com" target="_blank" class="btn">Visit Site</a>
<img src="image.jpg" alt="Description" width="300" height="200">

Common Attributes:

  • href - Specifies the URL for a link
  • src - Specifies the path to an image
  • alt - Specifies alternate text for an image
  • class - Specifies class names for elements
  • id - Specifies unique id for an element
  • style - Specifies inline CSS styles

🖼️ Media in HTML

HTML supports various media elements:

<img src="pic.jpg" alt="Picture">
<audio controls><source src="audio.mp3" type="audio/mpeg"></audio>
<video width="320" height="240" controls><source src="movie.mp4"></video>
